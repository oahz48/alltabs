# Security reporting

Please report suspected vulnerabilities privately to **oahz48@gmail.com**. Use a subject such as “Alltabs security report”. Do not post exploit details or personal browsing data in public issues.

Include the Alltabs version, Chrome version, operating system, expected and actual behavior, and reproduction steps using sample tabs. Redact credentials, account details, personal URLs, and unrelated browsing history. Do not send a browser profile or Chrome sync data.

The maintainer will investigate reports as availability permits; no response deadline is promised. Please coordinate disclosure with the maintainer so a fix can be prepared.

Alltabs 0.1.0 is the current submitted version. Older development snapshots have no separate maintenance commitment. See [PRIVACY.md](PRIVACY.md) for the local-data model and the distinction between Alltabs and Chrome's services.
