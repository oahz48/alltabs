# Public release roadmap

Current status and all remaining release gates are maintained in [docs/RELEASE.md](docs/RELEASE.md). Listing copy and disclosures are in [docs/STORE-LISTING.md](docs/STORE-LISTING.md).

Version 0.1.0 has automated quality checks, a verified package, and store materials. The website and privacy policy are live, and the owner confirmed Windows and macOS acceptance testing. The Chrome Web Store dashboard showed Pending review on September 7, 2026; publication has not been confirmed. GitHub publication preparation is tracked in [docs/OPEN-SOURCE.md](docs/OPEN-SOURCE.md), with public publication authorized at `oahz48/alltabs` under MIT.

Remote tab closing and direct OneTab integration remain separate future product decisions.
