# Design archive

Current assets live in `extension/icons/`, `docs/store-assets/`, and `website/assets/`. The folders here preserve design sources and rollback material; they are not shipped in the extension.

- `toolbar-icons-2026-09-13/original/`: original icon PNGs, SVG, manifest, and icon generator.
- `toolbar-icons-2026-09-13/supplied/`: supplied toolbar designs in all three shades. The original ZIP is stored beside this folder and remains ignored by Git.
- `green-logo-2026-09-13/`: approved green logo preview and historical trial notes.
- `icon-exploration-2026-09-10/`: earlier concepts and their source notes.
- `archived-unused-icons/`: retired experimental and neutral toolbar assets.
- `store-artwork-before-green/`: previous store artwork and website panel preview.

Cleanup on October 6, 2026 removed generated test build folders, temporary browser profiles, obsolete trial ZIPs, and stale listing captures. References to those files in trial notes are historical. Existing unpacked test folders under `dist/store-test-0.1.1*` were retained because Chrome may still use them. Release packages `dist/alltabs-0.1.1.zip` and `dist/alltabs-0.1.2.zip`, the Git recovery bundle, and current test evidence were preserved.
